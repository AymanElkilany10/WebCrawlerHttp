# WebCrawlerHttp
Project for learning Http Networking Course

This project is a simple web crawler built with Node.js, axios, and cheerio. Its main purpose is to crawl a website, collect all internal links, and generate a report of the site's structure. The project was created to practice building real-world applications and applying JavaScript and Node.js skills.


💡 Features

- Normalizes URLs for consistent internal link tracking

- Crawls all internal pages of a website

- Generates a report of links in the console

-  Includes automated tests using Jest
